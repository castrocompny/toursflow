# Marca ToursFlow

Ligadura T + F. Grade de 104, cantos da caixa em 24.

| Arquivo | Uso |
| --- | --- |
| `logo-mark.svg` | Símbolo em fundo claro ou neutro (caixa azul) |
| `logo-mark-light.svg` | Símbolo sem caixa, para fundo claro |
| `logo-mark-mono.svg` | Uma cor só, herda `currentColor`. Carimbo, bordado, fax de voucher |
| `logo-lockup.svg` | Símbolo + nome |
| `src/app/icon.svg` | Favicon e ícone de aba, gerado pelo Next |

Cores: `#072A38` (marinho), `#0E7C86` (teal), `#FF6A2B` (laranja).

Área de respiro mínima: metade da altura do símbolo em todos os lados.
Tamanho mínimo do símbolo: 20 px. Abaixo disso os cortes diagonais fecham.

O nome no `logo-lockup.svg` usa Bricolage Grotesque por referência de fonte.
Para gráfica, mídia impressa ou perfil de rede social, converta o texto em
curvas antes de enviar, senão a fonte é substituída no destino.
